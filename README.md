## 프로젝트 소개

fullweight는 체중, 체성분, 식단, 사진, 운동/음주 기록을 한 곳에서 관리하는 건강 관리 앱입니다.

핵심 목표는 다음과 같습니다.

- 체중 변화 추적
- 체지방/골격근량/허리둘레 같은 체성분 추적
- 식사 기록과 영양소 관리
- 음식 사진을 통한 AI 영양 분석
- 반복적으로 먹는 음식을 빠르게 재사용할 수 있는 즐겨찾기 기능
- 그래프와 캘린더를 통해 한눈에 변화 확인
- 필요 시 Google Drive 백업/복원 지원

이 앱은 Expo + React Native를 기반으로 만들었고, 모바일 UX를 우선으로 설계되어 있습니다. 웹에서 일부 화면 확인은 가능하지만, 광고/Google 로그인/현실적인 모바일 동작은 실제 기기 또는 네이티브 빌드 환경에서 검증하는 것이 가장 정확합니다.

## 빠른 시작 가이드 (일반 사용자)

### 1. 처음 앱을 켰을 때

- 기본 화면은 오늘 날짜의 체중/체성분 기록 화면입니다.
- 몸무게는 필수값이 아니며 비워두고 저장할 수 있습니다.
- 허리둘레, 골격근량, 체지방률, 체지방량은 필수는 아니며 선택 입력 항목입니다.
- `운동`, `음주`는 토글로 간단하게 체크할 수 있습니다.
- 사진을 추가하면 눈바디 사진이나 식단 사진을 함께 남길 수 있습니다.

### 2. 오늘의 기록 작성

- 하단 또는 표시된 입력 영역에서 몸무게, 허리둘레, 체지방률 등 값을 입력합니다.
- 숫자 입력 칸은 문자 입력이 들어오면 즉시 정리되도록 처리되어 있어 잘못된 값이 남지 않습니다.
- 기록을 저장하면 캘린더와 그래프 화면에서 바로 반영됩니다.
- 저장 시 조건에 따라 전면 광고가 나오기도 합니다.

### 3. 식사 추가하기

- 아침, 점심, 저녁, 간식 카드에서 식사 입력 모달을 엽니다.
- 음식 이름을 입력하고, 영양소를 입력하면 칼로리가 자동 계산됩니다.
- 사진을 찍어 AI 분석을 요청하면 음식 종류와 영양 정보를 자동으로 추정할 수 있습니다.
- 자주 먹는 음식은 즐겨찾기에 저장해 두면 다음에 다시 빠르게 불러올 수 있습니다.

### 4. 즐겨찾기 사용하기

- 식사 추가 모달에서 "즐겨찾기" 버튼을 누르면 저장해 둔 음식 목록이 열립니다.
- 검색창으로 음식 이름을 찾을 수 있습니다.
- 하트 버튼을 눌러 찜한 음식으로 지정하면 우선적으로 상단에 정렬됩니다.
- 정렬 메뉴에서 사용자 정의, 이름 오름차순, 이름 내림차순, 최신순, 오래된순을 선택할 수 있습니다.
- 길게 누르고 드래그하면 사용자 정의 순서를 바꿀 수 있습니다.
- 원하는 음식을 탭하면 이름과 탄수화물/단백질/지방이 자동으로 채워집니다.

### 5. 그래프와 캘린더로 변화 보기

- 그래프 탭에서 몸무게, 체지방, 허리둘레 등 지표를 선택해 추세를 확인할 수 있습니다.
- 캘린더 탭에서는 월 단위로 기록 상태를 한눈에 파악할 수 있습니다.
- 특정 날짜를 눌러 상세 기록을 수정하거나 삭제할 수 있습니다.

### 6. 데이터 보호와 백업

- 앱은 로컬 저장소에 기록을 저장합니다.
- 설정에서 Google Drive 백업/복원 기능을 사용할 수 있습니다.
- 현재 앱은 일반적으로 `AsyncStorage` 기반 로컬 저장과 Google Drive 메타데이터 백업을 함께 운영합니다.

## 즐겨찾기 기능

### 사용자 관점

음식 추가 화면에서 바로 자주 먹는 음식을 저장하고 다시 불러오는 기능입니다. 특히 같은 음식의 탄수화물, 단백질, 지방, 칼로리를 매번 다시 입력하는 수고를 줄여줍니다.

사용 흐름은 다음과 같습니다.

1. 식사 추가 모달에서 "즐겨찾기" 버튼을 누름
2. 저장된 음식 목록이 모달로 열림
3. 검색으로 음식 찾기
4. 원하는 음식 선택 시 이름과 영양소 값 자동 입력
5. 새 음식은 직접 추가 가능
6. 즐겨찾기 목록은 정렬/찜/사용자 정의 순서로 관리 가능

### 저장 동작

즐겨찾기 음식은 다음 구조로 저장됩니다.

```ts
{
  id: "...",
  name: "닭가슴살 볶음밥",
  carb: 40,
  protein: 25,
  fat: 12,
  kcal: 420,
  isFavorite: true,
  createdAt: "2026-09-10T12:34:56.000Z"
}
```

주요 특징:

- 이름 중복 저장을 방지합니다.
- 이름 앞뒤 공백, 중복 공백은 정리됩니다.
- `isFavorite` 값이 있으면 하트 표시를 기준으로 우선 정렬합니다.
- 생성 시간이 저장되므로 최신순/오래된순 정렬이 가능합니다.

### 정렬 방식

현재 지원되는 정렬은 다음과 같습니다.

- 사용자 정의
  - 드래그로 직접 순서를 바꿀 수 있음
- 이름 오름차순
- 이름 내림차순
- 최신순
- 오래된순

하트로 찜한 음식은 필터 버튼을 눌러 "찜한 음식 우선" 모드를 켤 수 있으며, 이 경우 찜한 음식을 위쪽에 배치한 뒤 나머지 음식들을 이어서 보여줍니다.

### 사용자 정의 정렬과 드래그

사용자 정의 정렬 모드에서는 항목을 길게 누르면 드래그 재정렬이 가능하도록 구현되어 있습니다.

- 드래그 중에는 애니메이션이 적용됩니다.
- 저장 후 다시 열어도 순서가 유지됩니다.
- 정렬 상태는 로컬 저장소에 반영됩니다.

### 검색 기능

검색창에서 입력하면 입력 즉시 목록이 필터링됩니다. 예를 들어 "닭"을 입력하면 닭 관련 음식만 표시됩니다.

이 기능은 입력값을 매 타이핑마다 확인해 실시간 필터링하는 방식으로 동작합니다.

### 중복 처리

같은 이름의 음식은 저장 시 자동으로 중복 검사하고 기존과 동일한 이름으로는 다시 추가할 수 없도록 막아둡니다. 이 로직은 이름의 공백과 대소문자 차이를 제거한 뒤 비교합니다.

### 로컬 저장 및 백업

즐겨찾기 항목은 로컬 저장소에 보관되며, Google Drive 백업 메타데이터에도 포함됩니다. 따라서 앱이 재설치되거나 백업 복원 작업을 수행해도 저장된 음식을 이어서 사용할 수 있습니다.

## 페이지별 기능

### 1. 기록 탭 (`/`)

날짜별 신체 데이터를 입력하고 저장하는 메인 화면.

| 항목                | 설명                                         |
| ------------------- | -------------------------------------------- |
| 날짜 선택           | 미니 캘린더로 날짜 이동. 기본값은 오늘       |
| 몸무게              | kg 단위 입력. 입력 생략(체중 없이 저장) 가능 |
| 허리둘레            | cm 단위 (선택)                               |
| 골격근량            | kg 단위 (선택)                               |
| 체지방률 / 체지방량 | % / kg 단위 (선택)                           |
| 운동 여부           | 토글 스위치                                  |
| 음주 여부           | 토글 스위치                                  |
| 사진                | 카메라 촬영 또는 갤러리에서 선택             |
| 메모                | 자유 텍스트                                  |
| 사용자 정의 수치    | 설정에서 추가한 커스텀 수치 항목             |
| 사용자 정의 체크    | 설정에서 추가한 커스텀 불리언 항목           |
| 식단 기록           | 하단 식사 카드에 아침/점심/저녁/간식 입력    |
| AI 음식 분석        | 음식 사진 촬영 → 칼로리·탄·단·지 자동 분석   |
| 기록 목록           | 최근 7개 기록 표시. 더보기로 전체 조회       |
| BMI 표시            | 신장 설정 시 현재 몸무게 기준 BMI 자동 계산  |

---

### 2. 그래프 탭 (`/explore`)

저장된 기록을 선 그래프로 시각화.

- **지표 선택**: 몸무게·허리둘레·골격근량·체지방률·체지방량·사용자 정의 수치·영양소(칼로리·탄·단·지)
- **기간 모드**: 일별·주별·월별·사용자 지정 기간
- **멀티 지표**: 여러 지표를 동시에 오버레이
- **날짜 범위 선택**: 캘린더 팝업으로 커스텀 기간 지정
- **그래프 스와이프**: 좌우 드래그로 데이터 탐색

---

### 3. 캘린더 탭 (`/calendar`)

월 단위 달력으로 기록 현황 한눈에 보기.

- 날짜 셀에 체중 표시. 운동·음주 여부 아이콘 표시
- 날짜 탭 → 해당일 기록 상세 / 편집 / 삭제
- 월·분기·연간 요약 통계 (평균 체중, 운동일수 등)
- 스와이프로 월 이동

---

### 4. 챌린지 탭 (`/challenge`)

목표 체중 달성을 위한 D-day 챌린지 기능.

- 시작 체중·목표 체중·기간 설정
- 진행률 바 시각화
- 일별 필요 감량량 자동 계산
- 챌린지 완료/포기 시 히스토리 저장
- 과거 챌린지 목록 열람

---

### 5. 눈바디 탭 (`/photos`)

날짜별로 촬영한 체형 사진 갤러리.

- 3열 썸네일 그리드
- 사진 탭 → 전체화면 뷰어 (날짜·체중 표시)
- **비교 모드**: 두 날짜의 사진을 좌우 나란히 비교
- 기록 탭에서 사진 첨부 시 자동 등록

---

| 스토어 (인앱 결제)  | 배너 광고 제거, AI PRO 구독, 후원 상품                      |
| 개발자 도구         | 설정 하단 "개발자 정보" 10회 탭 → 숨김 메뉴 (dev 빌드 전용) |

## 광고 정책

### 광고 종류

| 종류                   | 위치                     | 조건                           |
| ---------------------- | ------------------------ | ------------------------------ |
| 배너 광고              | 하단 탭바 위 (항상 노출) | 무료 유저                      |
| 전면 광고 (인터스티셜) | 전체화면 팝업            | 체중 저장 3회마다 1회          |
| 리워드 광고            | 전체화면 팝업            | AI 무료 횟수 소진 시 시청 선택 |

### 광고 트리거 상세

**배너 광고**

- 무료 유저에게 항상 노출
- `bannerRemoved` 또는 `aiPro` 구매 시 완전 제거

**전면 광고 (체중 저장)**

- 누적 저장 횟수가 3의 배수(3, 6, 9...)일 때 1회 노출
- 카운터는 앱 데이터 삭제 전까지 누적 (날짜 리셋 없음)
- AI PRO 구독 시 표시 안 됨

**리워드 광고 (AI 추가 사용)**

- 하루 무료 AI 분석 2회 소진 후, 리워드 광고 시청으로 당일 카운터 리셋 가능
- 시청 완료 시 → 당일 2회 다시 사용 가능
- AI PRO 구독 시 횟수 제한 자체가 없어져 리워드 광고 미노출

**AI 일일 카운터**

- 기준: KST 자정(00:00) 리셋
- 저장 키: `ad_ai_daily_count` (AsyncStorage)

**체중 저장 카운터**

- 누적 횟수 저장 키: `ad_weight_save_count` (AsyncStorage)
- 날짜 무관, 앱 초기화 전까지 계속 누적

### RevenueCat 키

### 개발자 도구 (숨김 메뉴)

- 기능:
  - 더미 데이터 약 3년치 생성
  - 배너 광고 제거 강제 활성 (`dev_banner_removed`)

  - 체중 저장 카운터 초기화
  - 멤버십 강제 무료 전환

## 빌드 & 배포

### 스크립트

```bash
# 개발 서버 (Metro)
npm run start

# Dev Client 연결용 개발 서버
npm run start:dev          # npx expo start --dev-client

# 에뮬레이터 직접 실행
npm run android

# EAS 클라우드 빌드
npm run build:dev          # development APK (Dev Client)
npm run build:preview      # preview AAB (테스트 광고 적용)
npm run build:prod         # production AAB (실제 광고 적용)

# 로컬 빌드
npm run build:dev:local
npm run build:preview:local
npm run build:prod:local
```

### 빌드 프로필 비교

| 프로필      | 파일 형식 | 광고   | 결제             | 패키지 |
| ----------- | --------- | ------ | ---------------- | ------ |
| development | APK       | 테스트 | 스킵 (`__DEV__`) | `.dev` |
| preview     | AAB       | 테스트 | 정상             | 정식   |
| production  | AAB       | 실제   | 정상             | 정식   |

> **주의**: 내부 테스트/비공개 테스트 배포 시 preview 프로필 사용 권장.  
> 테스트 기간 중 실제 결제가 발생할 수 있으므로 테스터 계정은 반드시 라이선스 테스터로 등록.

### 버전 관리

- `app.config.ts` → `version` (사용자에게 보이는 버전, e.g. 1.0.0)
- `app.config.ts` → `android.versionCode` (스토어 내부 버전 코드, 업로드마다 +1)
- `eas.json` → `appVersionSource: local` (수동 관리 모드)
